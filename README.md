# 정보보호증적관리시스템 (HISTORY) — 대시보드 UI/UX 개편 프로토타입

건강보험심사평가원(HIRA) 정보보호증적관리시스템의 메인 대시보드 개편 데모입니다.

## 개편 방향
- 밝은 테마(화이트/그레이 기반), 포인트 색 인디고-블루(#2563eb)
- Bootstrap3 + Color Admin 템플릿 → 모던 카드 기반 레이아웃으로 재설계
- 사이드바 · 헤더 · 본문 기본틀 포함

## 구성
- 상태 카운터 6종 (대기/진행/지연/처리중/반려/완료)
- 통제분야별 진행통계 (탭 전환)
- 처리상태 분포 도넛 (순수 SVG, 외부 의존성 없음)
- 사이버 위기경보 4단계
- 공유게시판 · 컴플라이언스 일정 달력

## 실행
정적 파일이라 `index.html`을 브라우저로 열면 됩니다.
Netlify 배포 시 이 폴더를 그대로 올리면 자동 게시됩니다.

숫자·목록은 실제 화면 기반의 목업 데이터입니다.
